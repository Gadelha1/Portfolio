# Portfólio — Gabriel Gadelha

Meu portfólio pessoal, trazendo como referência uma ficha de personagem de RPGs, então cada sessão do site é uma parte da minha ficha, com atributos, habilidades, conquistas e a trilha de projetos da faculdade.

## Por que foi feito

Foi requerido como atividade pela matéria de Laboratório de Desenvolvimento Multiplataforma, do 6º Semestre do curso de Desenvolvimento de Software Multiplataforma, mas pensei em deixar pessoal, trazer meus interesses em jogos e RPG, e juntar tudo isso pra ser também o ponto de contato para futuros trabalhos e etc.

## Stack

- **Vite + React + TypeScript**
- **Tailwind CSS** + CSS por componente

## Como rodar

```bash
npm install       # instala as dependências
npm run dev       # servidor de desenvolvimento em http://localhost:5173
npm run build     # gera o build de produção em dist/
npm run preview   # pré-visualiza o build de produção
```
